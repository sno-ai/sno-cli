sno 1.1.0
The Sno command line

Commands:
  setup       Install the default or selected catalog product
  init        Initialize independent CLI state and entry skills
  onboarding  Configure and prove the selected Station installation
  skills      List agent instructions, or read one by name
  products    List optional product offers, or record a reply to one
  update      Update CLI and actually installed products
  doctor      Check CLI updates, installed products, skills and Station state
  usage       Show remaining model allowance and purchased balance
  memory      Use memory installed for Claude or Codex
  observe     Send observability events
  project     Report local project memory and recursive self-improvement records
  uninstall   Uninstall one installed product, or all of them
  account     Manage account and machine identity
  rem         Send REM runs and human verdicts to SNO
  station     Manage this SNO Station

More:
  sno <command> --help   details and examples for one command
  --json                 machine-readable output for any command

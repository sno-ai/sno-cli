The unified command-line interface for SNO

Additional commands can be installed as external subcommands named sno-<command>.

Usage: sno [OPTIONS] [COMMAND]

Commands:
  assemble  Install core programs and agent skills
  update    Update installed programs and skills
  doctor    Check installed programs, skills and station state
  remove    Remove installer-owned files
  account   Manage account and machine identity
  station   Manage this SNO Station
  help      Print this message or the help of the given subcommand(s)

Options:
      --json
          Emit stable JSON output

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

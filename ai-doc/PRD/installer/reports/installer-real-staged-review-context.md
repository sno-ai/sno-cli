This is a new test-only verifier for the existing installer PRD QCG-2. Review its ability to catch false acceptance on the actual staged data, strict malformed-declaration refusal, per-program version/need decisions, root alias/custom-root planning, file/stamp mapping, actual utility help, and changed owned targets through update. The producer disclosed runtime copies in candidate skill payloads; final text-only publication is not asserted here.
